# Spec: Monitor 巡检结果多条件筛选器

> 版本: v1.0 | 日期: 2026-06-25 | 状态: 待确认

## Objective

在 Monitor 巡检结果表格上添加多条件筛选功能，替换当前占位死 UI。用户可通过 6 列下拉多选器组合筛选，AND 交集逻辑，筛选状态在翻页和 tab 切换间保持。

## 筛选列定义

| 列 | session_state key | 选项来源 | 空值 |
|----|------------------|---------|------|
| 平台 | `monitor_filters.platform` | `platform_labels` 中的值（动态，仅显示有数据的平台） | — |
| 严重度 | `monitor_filters.severity` | P0, P1, P2, P3, 未知 | 空→"未知" |
| 状态 | `monitor_filters.status` | 新增, 已标记 | — |
| 匹配关键词 | `monitor_filters.keyword` | 当前 harvest 中出现的所有关键词（动态提取） | — |
| 热度 | `monitor_filters.heat` | 有, 未知 | 空→"未知" |
| 时间 | `monitor_filters.time` | 有, 未知 | 空→"未知" |

## 筛选逻辑

- **不选任意选项 = 该列不过滤**（即显示该列所有值）
- **多列组合 = AND 交集**
- 所有列都不选 → 显示全部结果
- 筛选结果为空 → 提示"无匹配结果，请调整筛选条件"

## 交互设计

### 筛选面板
- `st.expander("🔍 多条件筛选")`，默认折叠
- 活跃筛选时标签显示 `"🔍 多条件筛选 (N项激活)"`
- 面板内：6 个 `st.multiselect`（2行×3列布局）+ 1行按钮

### 按钮行为
- **应用筛选**：锁定筛选条件 → 重置页码到 0 → 重新渲染
- **重置**：清空所有 multiselect → 重置页码到 0

### 状态持久化
- 筛选条件存 `st.session_state.monitor_filters`（dict）
- 翻页不丢失，切换 tab 后回来保持
